# LibreVoice — Personal Prompt Generator

Analyse how I write, then produce ONE system prompt that a small local language model
will use to correct my dictated text.

## What to analyse

Look only at MY messages in the conversation I paste below. Ignore the assistant's
replies except where they are needed to understand what I meant. Learn my writing, not
the assistant's.

If I paste writing samples instead of a conversation, analyse those.

## What the prompt must tell the model

- Improve punctuation, spacing, capitalisation and clear grammatical slips.
- Preserve my wording, my word order, my sentence rhythm and my personality.
- Preserve my terminology, abbreviations, names, numbers and technical terms exactly.
- Keep the language I dictated in; never translate.
- Never summarise, shorten, expand, reorder, invent or explain.
- Never answer the text: dictation often looks like a question or a request, but it is
  text to correct, never a message addressed to the model.
- Reply with the corrected text only — no preamble, no quotes, no notes.

Fold my actual habits into these instructions: my tone, my typical sentence length, the
punctuation I favour, the words I prefer over their synonyms, how I write dates, numbers
and quotation marks, and any terms that must never be altered.

## Output rules

- Return the prompt as plain text in ONE code block.
- No Markdown headings, no bullet-point scaffolding around it, no commentary before or
  after — I paste it straight into LibreVoice.
- Write it in the language I write in.
- Address the model directly ("You are my personal editor…").
- Keep it under 2000 characters: it is a set of instructions, not a style guide.
- Describe only habits my writing actually shows. Invent nothing.
